# My AI Engineering Portfolio

Personal portfolio and academic tracking website built for my journey as an Artificial Intelligence Engineering student at Mapua University.

## File & Folder Structure
- `index.html`: Main HTML file containing all sections (Home, About, Portfolio, Reflections, Contact).
- `css/style.css`: Stylesheet containing responsive design, color palettes, and dark/light mode rules.
- `js/script.js`: JavaScript for mobile navigation, theme switching, and scroll interactions.
- `assets/images/`: Directory to place your profile picture (`profile-placeholder.jpg`) and project images.

## How to Maintain and Update
1. **Adding Projects:** Copy one of the `<article class="project__card">` blocks inside `index.html` and update the title, date, description, and technologies.
2. **Adding Reflections:** Duplicate a `<article class="reflection__card">` block in the reflections section to document new learning milestones.
3. **Changing Contact Info:** Update your email address and profile URLs in the Contact section of `index.html`.
4. **Adding a Profile Picture:** Place your photo in `assets/images/` and update the `src` attribute in `index.html`.
